# qrcode-generator

Le fichier `src/cibles/statique/qrcode-donnees.ts` contient le code de
qrcode-generator 2.0.4 (https://github.com/kazuhikoarase/qrcode-generator),
copyright (c) 2009 Kazuhiko Arase, publié sous licence MIT
(http://www.opensource.org/licenses/mit-license.php).

Il est recopié dans le site statique produit (`humalis/qrcode.js`) quand une
page contient un code QR. « QR Code » est une marque déposée de DENSO WAVE
INCORPORATED.
